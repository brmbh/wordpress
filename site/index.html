The difference

Empty boilerplate is a dead end. brmbh ships boilerplate plus an agent that builds.

Every other WordPress starter hands you scaffolding and wishes you luck. brmbh ships the same clean foundation — and an agent that plans your blocks, generates the four-file ACF factory, and fills the fields from your design. You review and ship.

What's in the box

A foundation that earned its parts.

ACF block factory

Drop a four-file folder into my-acf-blocks/ and it self-registers. WordPress-standard block.json — AEO-ready.

Bootstrap 5 ↔ Gutenberg

One variable layer bridges Bootstrap's grid and utilities to the block editor. Editors never type a class.

Agent skills built in

Canonical AGENTS/ skills, with auto-generated wrappers for Claude, Cursor & Windsurf.

Figma token pipeline

Pull design tokens from Figma Variables straight into _tokens.scss. Design system stays in sync.

Deploy & DB suite

Rsync deploys and database pull/push between environments — wrapped behind clean, guarded commands.

Code-first CLI

One CLI for the whole lifecycle. Every command speaks human and machine — pass --json for agents.

One CLI · four jobs

Small surface. Whole lifecycle.

01 — Scaffolding

Start & grow a project

  • create scaffold, install, build, wire skills, activate
  • add block four-file ACF block, factory convention
  • add cpt one-file custom post type
  • add skills regenerate agent wrappers from AGENTS/
02 — Dev operations

Day-to-day tooling

  • dev build & watch CSS + JS
  • doctor health check — node, theme, build, ACF Pro
03 — Cloud deploy

Ship it

  • deploy staging push to a staging environment
  • deploy prod promote to production
04 — DB & sync

Move data safely

  • db pull remote database → local
  • db push local database → remote
Built for agents

Every command speaks human and machine.

The same command that prints friendly steps for you returns a clean JSON envelope for an agent — with a stable contract and a level that says exactly how to use the result. Deterministic work runs in code; the reasoning stays with the model.

  • L1  raw data — the agent interprets
  • L2  a class to branch on — like doctor
  • L3  a literal next-step procedure — like create
